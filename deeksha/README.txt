AYYAPPA DEEKSHA COUNTDOWN
=========================

1) GET THE WALLPAPERS (one time)
   Download the three Higgsfield images and save them in the "assets" folder with these exact names:
     wallpaper-ayyappa.jpg
     wallpaper-sannidhanam.jpg
     wallpaper-shiva.jpg
   (Links are in config.js next to each name.) If a file is missing, the page loads it from Higgsfield online instead.

2) OPEN AS A TAB
   Double-click index.html -> it opens in your browser. Pin the tab (right-click tab > Pin).

3) OR MAKE IT YOUR NEW TAB PAGE (Chrome / Edge / Brave)
   chrome://extensions -> turn on Developer mode -> Load unpacked -> pick this folder.
   Every new tab now opens the countdown. Chrome will ask once to "keep changes" - click Keep.

CHANGE DATES / TITLE
   Gear icon (bottom right) -> Settings. Saved in this browser.
   Or edit config.js to change the defaults.

ADD YOUR OWN WALLPAPER
   Drop a .jpg into assets/ and add a line to the wallpapers list in config.js.
